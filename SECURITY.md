# Security

This repository contains curated documentation and media references. It does not operate the linked model services.

Report broken links, incorrect examples, or misleading model claims through a repository issue. Include the affected file and section and the relevant public source.

For exposed credentials or private information, avoid repeating the sensitive data in a public issue. Use GitHub's content-reporting controls or the contact information published on a maintainer's GitHub profile. Reports concerning a linked service should go to that service's own security or support channel.
